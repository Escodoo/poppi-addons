This module extends the Brazilian Fiscal of the Odoo system to support automatic compensation accounting entries.

Functionalities:

* Adds compensation configuration to CFOP (Fiscal Operation Code)
* Automatically creates compensation accounting entries on invoice posting
* Configurable value sources for compensation (Cost, Sale Price, or Compensation Value)
* Flexible debit/credit account type selection (Asset or Liability)
* Support for product-specific compensation values
* Automatic journal entry creation with proper accounting treatment
