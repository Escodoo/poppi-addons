Prints one copy of the invoice per payment installment, including the
fiscal document number when available, the due date and a table of
installment amounts. The table highlights the installment for the
current copy.

**Table of contents**

.. contents::
   :local:

Usage
=====

Open an invoice or vendor bill in Accounting and print its PDF. Invoices
with payment installments start each installment on a new page.
